# Recovered Garmond Route references

Source: [Speedrunner Achievement Guide: The Garmond Route!](https://steamcommunity.com/sharedfiles/filedetails/?id=3577460696), by Tay Bravo. Annotated map bases are from [MapGenie’s Pharloom map](https://mapgenie.io/hollow-knight-silksong/maps/pharloom); game screenshots are Hollow Knight: Silksong by Team Cherry.

The three previously saved maps are preserved. On 2026-11-09, 16 additional original images were recovered directly from the guide’s Steam image links. All files retain their original bytes. [catalog.json](../assets/maps/catalog.json) records source URLs, dimensions, byte counts, SHA-256 hashes, and route relevance.

The app shows 12 reference maps and 3 relevant screenshots. Guide-only Mist and Sister Splinter skip alternatives are preserved in `assets/maps/` but excluded from the timed route and gallery. The timed route fights Sister Splinter. The original guide text is condensed into route directions and numbered map keys, with the decisions in `HANDOFF.md` applied. Original map numbers stay intact; planned, optional, skipped and resource-backup entries describe our path. The original 13 travel-section titles organize the runbook, with a labeled Greymoor return and explicit notices for the four missing maps.

## Missing guide maps

The current guide HTML has empty image URLs for these four maps:

- Shellwood and Widow
- Deep Docks return: mask shard and Forge Daughter
- Last Judge and Choral Chambers
- Songclave, lower Cogwork and Vaults arena

The separate Vaults shard/Pale Oil map has been recovered. The guide does not mark spool fragments on its maps; the six selected fragments retain their MapGenie pins in the runbook. Custom screenshots can fill these gaps.

## Adding a local screenshot

Save the original image in `assets/maps/`. Add an entry to `assets/maps/catalog.json` with a unique `id`, a `/maps/` URL in `src`, repository-relative `file` under `assets/maps/`, `mime`, `width`, `height`, `bytes`, `sha256`, `kind` (`map` or `screenshot`), `timedRoute`, `title`, `note`, `sourceUrl`, and recovery date. For your own image, leave `sourceUrl` empty and set `creator`. Use a checkpoint’s `maps` array in [data/route.json](../data/route.json) to link it there; otherwise the section’s `maps` array applies. Restart the local server after adding a new file. Run `npm run check` before committing.
